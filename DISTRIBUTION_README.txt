Library Management System

Run LibraryManagementSystem.exe to start the application.

Default accounts:
- Admin: username admin, password Admin@123
- Librarian: username librarian, password Librarian@123

The SQLite database is created and updated automatically on first run. The app stores its local database and settings next to the executable unless appsettings.json points to a different location.

For barcode scanning, connect or enable a Windows-compatible camera before using the Scan button in the Add/Edit Book dialog.
