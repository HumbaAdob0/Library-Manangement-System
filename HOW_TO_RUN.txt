========================================
HOW TO RUN THE LIBRARY MANAGEMENT SYSTEM
========================================

FOR DEVELOPERS (Running from Source)
=====================================

METHOD 1: Double-click the batch file (EASIEST)
------------------------------------------------
1. Double-click "RUN_APP.bat" in this folder
2. Wait for it to build and start
3. The application will open

METHOD 2: Using Command Line
-----------------------------
1. Open Command Prompt or PowerShell
2. Navigate to this folder
3. Run:
   cd LibraryManagementSystem.Wpf
   dotnet run

METHOD 3: Build and Run Executable
-----------------------------------
1. Build: dotnet build "LibraryManagementSystem.Wpf\LibraryManagementSystem.Wpf.csproj"
2. Run: LibraryManagementSystem.Wpf\bin\Debug\net10.0-windows\LibraryManagementSystem.exe


FOR END USERS (Creating Standalone Executable)
===============================================

OPTION 1: Full Distribution Package (RECOMMENDED)
--------------------------------------------------
Run: CREATE_DISTRIBUTION.bat

This creates a ready-to-share folder with everything needed.
- File size: ~150-200 MB
- No .NET installation required
- Users just double-click the .exe

OPTION 2: Self-Contained Single File
-------------------------------------
Run: BUILD_SINGLE_EXE.bat

Creates: LibraryManagementSystem.exe (~150-200 MB)
- Includes .NET runtime
- No installation required
- Larger file size

OPTION 3: Framework-Dependent (Smaller)
----------------------------------------
Run: BUILD_SMALL_EXE.bat

Creates: LibraryManagementSystem.exe (~5-10 MB)
- Requires .NET 10.0 Runtime on target PC
- Much smaller file size
- Download .NET from: https://dotnet.microsoft.com/download/dotnet/10.0

After building, find the .exe at:
LibraryManagementSystem.Wpf\bin\Release\net10.0-windows\win-x64\publish\

IMPORTANT: Always include these files together:
- LibraryManagementSystem.exe
- appsettings.json
- library.db (created automatically on first run)

TROUBLESHOOTING
===============

"Cannot find appsettings.json"
-------------------------------
- Ensure appsettings.json is in the same folder as the .exe

"The application requires .NET Runtime"
---------------------------------------
- Install .NET 10.0 Runtime from: https://dotnet.microsoft.com/download/dotnet/10.0
- OR rebuild with self-contained option (BUILD_SINGLE_EXE.bat)

Database Issues
---------------
- Delete library.db to reset (WARNING: deletes all data)
- The app will create a fresh database on next run

Old Design Showing
------------------
1. Delete old bin folder: del /s /q bin
2. Rebuild: dotnet build "LibraryManagementSystem.Wpf\LibraryManagementSystem.Wpf.csproj"
3. Run using METHOD 1 or METHOD 2


DATABASE LOCATION
=================
Development: LibraryManagementSystem.Wpf\library.db
Production: Same folder as the .exe file

All changes are saved here and will persist.


SYSTEM REQUIREMENTS
===================

- 1280x720 screen resolution or higher
